# Graph Academy Lab

Academia web gratuita de 24 semanas para aprender grafos, Neo4j Aura, ArcadeDB, modelado de conocimiento, RDF, SKOS, OWL y GraphRAG.

## Contenido

Siete módulos con lecciones introductorias, ejercicios, enlaces oficiales y seguimiento local de módulos explorados.

**Estado:** primera versión del temario; el contenido se ampliará progresivamente. No es aún un curso exhaustivo de 24 semanas.

## Publicación

Sitio estático sin compilación. Para habilitar GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

URL prevista: https://athurdavy.github.io/graph-academy-lab/
