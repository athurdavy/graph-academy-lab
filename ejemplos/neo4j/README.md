# Laboratorio Neo4j AuraDB — Biblioteca ficticia

1. Crea una instancia AuraDB de pruebas.
2. Ejecuta `01_biblioteca.cypher` en el editor de consultas.
3. Copia `.env.example` a `.env` y rellena credenciales **solo en tu ordenador**.
4. Instala dependencias con `python -m pip install -r requirements.txt`.
5. Ejecuta `python app.py`.
6. Consulta las [semanas 4–7](../../temario/README.md) para teoría, prácticas y retos.

No subas `.env`, contraseñas ni datos privados. Todo el dataset incluido es ficticio.
